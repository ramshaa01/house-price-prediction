# 🏠 House Price Prediction System

A Machine Learning based web application that predicts house prices using the **XGBoost Regression Algorithm**. The application provides an easy-to-use interface where users can enter house details and receive an estimated house price instantly.

---

## 📖 Project Overview

The real estate industry often requires accurate property valuation to help buyers, sellers, and investors make informed decisions. This project uses Machine Learning techniques to predict house prices based on various property features such as area, number of bedrooms, bathrooms, parking spaces, and furnishing status.

The application is developed using **Python**, **Flask**, and **XGBoost Regression**, providing accurate and efficient price predictions through a simple web interface.

---

- Predict house prices using Machine Learning.
- Build a user-friendly web application using Flask.

# 📊 Dataset

The project uses the **Housing Dataset** containing various house-related features such as:

- Area
- Number of Bedrooms
- Number of Bathrooms
- Stories
- Main Road Access
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

These features are used to train the Machine Learning model for predicting house prices.

---

# ⚙ Data Preprocessing

Before training the model, the dataset was preprocessed by:

- Handling categorical features
- Encoding categorical values
- Feature selection
- Splitting training and testing datasets

---

# 🤖 Machine Learning Model

The project uses the **XGBoost Regression Algorithm**, an advanced ensemble learning technique known for:

- High prediction accuracy
- Faster training
- Reduced overfitting
- Better handling of complex datasets

---

# 🚀 How the System Works

1. User enters house details.
2. Flask receives the input.
3. Input is processed.
4. Trained XGBoost model predicts the price.
5. Predicted house price is displayed to the user.

# ▶ Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/House-Price-Prediction-System.git
```

Go to the project folder

```bash
cd House-Price-Prediction-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000/
```
